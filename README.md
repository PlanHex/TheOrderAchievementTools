# The Order Achievement Tools — Local Development Setup

Prerequisites:
- Docker Desktop (or another Docker Engine) installed and running.

Quick setup (Windows PowerShell):

```powershell
# from repository root
.\local\setup-local.ps1
```

Quick setup (Linux / macOS):

```bash
# from repository root
./local/setup-local.sh
```

What the setup does:
- Builds and starts the `web` and `db` containers defined in `local/docker/docker-compose.yml`.
- Waits for MySQL to become available.
- Creates the schema from `data/sql/sql_tables.sql` and imports CSVs from `data/` into the database.

**Important — Destructive Action**

- Running the setup scripts (`local/setup-local.ps1` or `local/setup-local.sh`) will DROP and RECREATE the `order_achievements` database tables and then repopulate them from the CSV files in `data/`.
- This will permanently overwrite any existing data in your local `order_achievements` database (including data stored in the Docker volume `db_data`).
- Back up your data before running the scripts. Example backup command (from repository root):

```powershell
# Dump the database from the running container
docker-compose -f local/docker/docker-compose.yml exec -T db mysqldump -u root -proot order_achievements > backup.sql
```

Run the setup only if you understand it will reset your local database.

Notes:
- The scripts use a temporary `mysql:8.0` client container to run the SQL and LOAD DATA commands; they rely on Docker Desktop's `host.docker.internal` for the client to reach the MySQL server.
- If you prefer to run commands manually, inspect `local/import_data.sql` (generated by the scripts) and the CSVs in `data/`.

If anything fails, check that Docker Desktop is running and that ports are available (MySQL on host port 3306, web on 8000).

Enjoy!
